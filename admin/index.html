Mỗi cột = tổng lượt gọi AI thành công (Groq + DeepSeek) trong ngày đó. Cần chạy server/migrate-12-admin-stats.sql để bắt đầu ghi số liệu.

Vì hệ thống gọi AI thẳng từ trình duyệt (không qua server riêng), số liệu ở đây chỉ mang tính THỐNG KÊ — không phải giới hạn chặn cứng số lượt gọi thật sự.

💾 Sao lưu & Khôi phục toàn bộ dữ liệu

Sao lưu tải về TOÀN BỘ dữ liệu server (mọi gia đình, mọi bảng) thành 1 file JSON — giữ file này ở nơi an toàn.

⚠️ Khôi phục từ file sao lưu

NGUY HIỂM — không thể hoàn tác: khôi phục sẽ XOÁ SẠCH toàn bộ dữ liệu HIỆN TẠI trên server rồi thay bằng ĐÚNG dữ liệu trong file bạn chọn. Bất kỳ thứ gì được tạo SAU thời điểm sao lưu đó (không có trong file) sẽ MẤT VĨNH VIỄN. Chỉ dùng khi thật sự cần đưa cả hệ thống về đúng 1 thời điểm cũ.
