# Kho asset Kenney — giấy phép CC0 (Public Domain)

Toàn bộ asset trong thư mục này tải từ https://kenney.nl/assets — giấy phép **CC0 1.0**
(dùng tự do mọi mục đích, không cần ghi công — nhưng ghi lại đây cho rõ nguồn).
Không có bất kỳ asset nào lấy từ game thương mại gốc.

| Pack | Dùng cho game |
|---|---|
| `fish-pack/` | Cá Lớn Biển Xanh (kiểu Feeding Frenzy) |
| `physics-assets/` | Ném Banh Đổ Tháp (kiểu Angry Birds — khối gỗ/đá/kính + quái) |
| `puzzle-pack-2/` | Rồng Con Bắn Trứng (kiểu Dynomite — bóng màu), Bóng Đỏ Phiêu Lưu (kiểu Bounce — bóng, ống) |
| `pixel-platformer/` | Nhà Thám Hiểm Tí Hon (platformer kiểu Mario — tilemap + nhân vật) |
| `racing-pack/` | Tay Đua Nhí (kiểu đua xe — xe hơi, mô tô, đường đua, cây cối) |
| `alien-ufo-pack/` | Gà Vũ Trụ (kiểu Chicken Invaders — UFO, quái xâm lăng) |
| `ui-pack/` | Nút bấm/khung/panel đẹp dùng chung mọi game (kèm âm thanh click) |
| `game-icons/` | Icon điều khiển (pause, âm thanh, mũi tên, home...) dùng chung |

Cấu trúc mỗi pack: `PNG/` (ảnh rời), `Spritesheet(s)/` (ghép sẵn + XML tọa độ), `Vector/` (SVG/EPS).
Khi làm game chỉ copy đúng những file cần vào `<game>/images/` để precache offline gọn.
