⚙️ Chưa kết nối server

Hệ thống quản lý bé cần một project Supabase (miễn phí, ~10 phút cài 1 lần):

  1. Làm theo hướng dẫn trong server/README.md của repo (tạo project → dán server/schema.sql).
  2. Điền Project URL + anon key vào file /server-config.js.
  3. Tải lại trang này để đăng ký tài khoản phụ huynh.

🤖 Trợ Lý AI (Groq)

Dùng để bấm "🤖 Ôn thêm với AI" trong Thi Chứng Chỉ Anh — tự sinh thêm câu hỏi trắc nghiệm mới cho từng unit. Lấy key miễn phí tại console.groq.com/keys.

⚠️ App này không có server riêng để giấu key — key được gọi thẳng từ trình duyệt đang mở. Dùng 1 key Groq riêng cho app này, đừng dùng chung với việc khác.
